# Держу слово 🔥

**Telegram Mini App для обещаний и небольших дел, которые легко забыть.**

Добавляй задачу себе или близкому, выбирай срок, прикрепляй фото и отмечай выполненное. Огонёк помогает не терять ежедневную серию.

> Это интерфейсный демо-прототип. Данные сохраняются в браузере на текущем устройстве; серверной синхронизации и настоящих Telegram-контактов пока нет.

## Возможности демо

- Светлая и тёмная темы.
- Список обещаний с фильтрами и сроками.
- Индикатор огонька, который становится ярче по мере приближения срока.
- Создание и редактирование задач: ответственный, дата, эмодзи и фото.
- Увеличение прикреплённого фото.
- Страницы «Люди», «Статистика» и «Профиль».
- Адаптивный интерфейс для телефона и компьютера.
- Подготовка к открытию внутри Telegram через Telegram Web Apps API.

## Открыть локально

Скачай `index.html` и открой его в браузере. Сборка и установка зависимостей не нужны.

## Опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Добавь `index.html` в корень репозитория.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажми **Save**.
5. После публикации GitHub покажет адрес сайта в разделе **Pages**.

## Подключить к Telegram

1. Создай бота через [@BotFather](https://t.me/BotFather), отправив `/newbot`.
2. В настройках бота подключи Main Mini App и укажи HTTPS-адрес GitHub Pages. Для запуска из кнопки меню используй `/setmenubutton`.
3. Открой профиль бота в Telegram и запусти приложение.

Подробности о способах запуска есть в [официальной документации Telegram Mini Apps](https://core.telegram.org/bots/webapps).

## Текущие ограничения

- Задачи, контакты и настройки темы хранятся в `localStorage` этого браузера. На другом устройстве будет отдельное хранилище.
- Экран приглашения демонстрационный: он не создаёт настоящую ссылку для совместного списка.
- Добавление по юзернейму сейчас сохраняет введённое имя локально. Поиск Telegram-пользователей и загрузка их аватаров не подключены.
- Напоминания от бота, вход через Telegram и общие списки потребуют серверной части.

## Технологии

- HTML, CSS и JavaScript без сборщика.
- Telegram Web Apps JavaScript API для запуска в Telegram.
- `localStorage` для демонстрационного хранения на устройстве.
